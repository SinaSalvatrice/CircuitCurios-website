5. CircuitCurios Studio

CircuitCurios Studio ist eine interne Anwendung zur Vorbereitung und Verwaltung CircuitCurios-eigener Produktbilder, Produktinformationen, Alt-Texte und Veröffentlichungsabläufe.

6. Pinterest-Integration

CircuitCurios Studio kann über den offiziellen OAuth-Ablauf und die Pinterest API mit einem autorisierten Pinterest-Konto verbunden werden. Abhängig von den erteilten Berechtigungen kann die Anwendung Informationen zu Boards abrufen sowie CircuitCurios- eigene Pins erstellen oder verwalten.

Pinterest-Passwörter werden von CircuitCurios Studio nicht abgefragt oder gespeichert. Die Verbindung entsteht nur nach ausdrücklicher Autorisierung durch den Kontoinhaber.

7. Daten im Rahmen der Pinterest-Integration

Je nach verwendeter Funktion können insbesondere folgende Daten verarbeitet werden:

  • von der Pinterest API bereitgestellte Konto- und Autorisierungsinformationen,
  • Board-Informationen,
  • Pin-Inhalte wie Bilder, Titel, Beschreibungen, Alt-Texte und Ziel-Links,
  • OAuth-Zugriffs- und Refresh-Tokens zur Aufrechterhaltung der autorisierten Verbindung.

8. Zweck und Weitergabe

Die Daten werden ausschließlich für die vom autorisierten Nutzer ausgelösten Pinterest-Funktionen innerhalb von CircuitCurios Studio verarbeitet. Daten werden nur soweit an Pinterest übertragen, wie dies zur Ausführung der jeweiligen Funktion erforderlich ist. CircuitCurios verkauft keine personenbezogenen Daten.

9. Speicherung und Widerruf

Soweit Autorisierungs-Tokens lokal gespeichert werden, dienen sie ausschließlich der Aufrechterhaltung der autorisierten Verbindung. Die Pinterest-Verbindung kann getrennt und die Berechtigung zusätzlich in den Einstellungen des verbundenen Pinterest-Kontos widerrufen werden.
