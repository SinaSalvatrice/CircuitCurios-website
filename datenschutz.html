Verantwortlich

CircuitCurios
Remscheid, Nordrhein-Westfalen, Deutschland

Datenschutzanfragen können über den öffentlich verlinkten CircuitCurios Etsy-Shop an CircuitCurios gerichtet werden.

1. Website

Diese Website stellt CircuitCurios, handgearbeitete Oberflächen, Schmuck und Objekte vor und verweist auf externe Verkaufsangebote. CircuitCurios setzt auf dieser Website keine eigenen Analyse- oder Marketing-Cookies ein und bindet keine eigenen Tracking-Dienste ein.

2. Hosting über GitHub Pages

Die Website wird über GitHub Pages ausgeliefert. Beim Abruf können technisch erforderliche Verbindungsdaten wie IP-Adresse, Zeitpunkt, angeforderte Ressource und Browserinformationen durch den Hosting-Anbieter verarbeitet werden.

3. Externe Links

Die Website enthält Links zu externen Diensten, insbesondere Etsy. Daten werden erst an den jeweiligen externen Anbieter übertragen, wenn ein entsprechender Link oder Dienst aufgerufen wird. Für externe Angebote gelten deren eigene Datenschutzbestimmungen.

4. Pinterest API und OAuth

CircuitCurios kann ein eigenes Pinterest-Konto über den offiziellen OAuth-Ablauf mit der Pinterest API verbinden. Die Verbindung dient ausschließlich dazu, CircuitCurios-eigene Inhalte auf Pinterest zu verwalten, beispielsweise Boards auszulesen sowie Pins mit Bildern, Titeln, Beschreibungen, Alt-Texten und Ziel-Links zu erstellen oder zu verwalten.

Pinterest-Zugangsdaten oder Passwörter werden von CircuitCurios nicht abgefragt. Eine Verbindung entsteht nur nach ausdrücklicher Autorisierung im offiziellen Pinterest-OAuth-Dialog.

5. Verarbeitete Pinterest-Daten

Abhängig von den erteilten Berechtigungen können insbesondere verarbeitet werden:

  • von Pinterest bereitgestellte Konto- und Autorisierungsinformationen,
  • Board- und Pin-Informationen,
  • Pin-Inhalte wie Bilder, Titel, Beschreibungen, Alt-Texte und Ziel-Links,
  • OAuth-Zugriffs- und Refresh-Tokens zur Aufrechterhaltung der autorisierten Verbindung.

6. Zweck, Speicherung und Weitergabe

Pinterest-Daten werden nur für die autorisierten CircuitCurios-Funktionen verarbeitet. Daten werden nur insoweit an Pinterest übertragen, wie dies für die jeweils ausgelöste Funktion erforderlich ist. CircuitCurios verkauft keine personenbezogenen Daten.

Soweit OAuth-Tokens gespeichert werden, dienen sie ausschließlich der Aufrechterhaltung der autorisierten Verbindung. Die Verbindung kann getrennt und die Berechtigung im verbundenen Pinterest-Konto widerrufen werden.

7. Änderungen

Diese Datenschutzerklärung wird angepasst, wenn sich Funktionen dieser Website oder angebundener Dienste wesentlich ändern.
