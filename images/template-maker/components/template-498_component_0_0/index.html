BIOLOGIE · FILTRATION
Porifera
Porifera überträgt das Prinzip biologischer Filtration auf eine plastische Oberfläche. Zwischen schmalen, organisch verbundenen Stegen öffnen sich unregelmäßige Poren, deren Abstände, Größen und Tiefen ständig variieren. Das Muster wirkt gewachsen, ohne sich in ein starres Raster einzuordnen.
Inspiriert von den Strukturen natürlicher Schwammkörper entsteht eine lebendige Textur, die mit Dichte und Offenheit spielt. Manche Bereiche verdichten sich, andere wirken nahezu durchlässig. So wird Filtration als räumliches Gefüge sichtbar.
