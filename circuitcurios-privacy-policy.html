Privacy enquiries can be sent to CircuitCurios via the publicly linked CircuitCurios Etsy shop.

1. This website

This website presents CircuitCurios, its handmade surfaces, jewellery and objects, and links to external sales channels. CircuitCurios does not operate its own analytics or marketing tracking on this website and does not set its own advertising cookies.

2. Hosting

This website is delivered through GitHub Pages. When the website is requested, technically necessary connection data such as IP address, time of access, requested resource and browser information may be processed by the hosting provider.

3. External links

This website links to external services, including Etsy. Data is only transferred to an external provider when a corresponding external link or service is opened. The privacy policies of those providers then apply.

4. Pinterest API and OAuth

CircuitCurios may connect its own Pinterest account to the Pinterest API using Pinterest's official OAuth authorization flow. The integration is used only to manage CircuitCurios-owned Pinterest content, for example to read boards and to create or manage Pins containing product images, titles, descriptions, alt text and destination links.

CircuitCurios does not request or store Pinterest passwords. Access is granted only after explicit authorization through Pinterest's official OAuth interface.

5. Pinterest data processed

Depending on the permissions granted, the integration may process:

  • account and authorization information supplied by Pinterest,
  • board and Pin information,
  • Pin content such as images, titles, descriptions, alt text and destination links,
  • OAuth access and refresh tokens required to maintain the authorized connection.

6. Purpose, storage and sharing

Pinterest data is processed only for the CircuitCurios functions authorized by the account owner. Data is sent to Pinterest only where required to perform the requested Pinterest function. CircuitCurios does not sell personal data.

OAuth tokens are retained only as needed to maintain the authorized connection. The Pinterest authorization can be revoked through the connected Pinterest account, and the CircuitCurios Pinterest connection can be disconnected.

7. Changes

This Privacy Policy may be updated when the website or connected service functions change materially.
